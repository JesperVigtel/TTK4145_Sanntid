ANSVARSFORDELING - LYS OG KOMMUNIKASJON
================================================================================

LOCALCONTROL STYRER DISSE LYS DIREKTE:
- Door light          → hardware.SetDoorOpenLamp()
- Cab call lights     → hardware.SetButtonLamp(BTCab, floor, on/off)
- Floor indicator     → hardware.SetFloorIndicator(floor)

LOCALCONTROL SENDER TIL DECISIONMAKER:
- NewButtonPress      → Knapptrykk (cab + hall) - nil hvis ingen ny
- CompletedOrder      → Hvilke ordrer som er fullført
- Elevator state      → Floor, Direction, Behaviour, ActiveStatus
- Obstructed          → true/false - dør blokkert

ActiveStatus brukes til:
- true  = Heisen fungerer (når floorChan mottas)
- false = Watchdog timeout (heis stuck)

Obstructed brukes til:
- true  = Dør blokkert, kan ikke lukkes
- false = Normal drift

DECISIONMAKER STYRER:
- Hall call lights    → Basert på global state og redundans

}

2. FLOORCHAN CASE - OnFloorArrival
================================================================================
Trigger: Heisen passerer en etasjesensor
Watchdog: Reset ved hver floor arrival (bevis på at heisen lever)

Steg-for-steg:
[ ] 2.1  Oppdater elevator.CurrentFloor = floor
[ ] 2.2  elevator.ActiveStatus = true (heisen lever - nådde en etasje)
[ ] 2.3  hardware.SetFloorIndicator(floor)  ← LOKAL LYS
[ ] 2.4  Hvis CurrentFloor == -1 (initialisering):
         [ ] Stopp motor, sett Idle, continue
[ ] 2.5  Kall shouldStop(elevator) for å avgjøre stopp
[ ] 2.6  Hvis shouldStop() == true:
         [ ] 2.6.1 hardware.SetMotorDirection(types.Stop)
         [ ] 2.6.2 motorActiveChan <- false  (stopp watchdog)
         [ ] 2.6.3 hardware.SetDoorOpenLamp(true)  ← LOKAL LYS
         [ ] 2.6.4 doorOpenChan <- true  (start dørtimer)
         [ ] 2.6.5 elevator.Behaviour = types.ElevatorDoorOpen
         [ ] 2.6.6 Bygg completed := getCompletedOrders(elevator, floor)
         [ ] 2.6.7 clearRequestsAtFloor(&elevator, floor)
         [ ] 2.6.8 Slå AV cab-lys: hardware.SetButtonLamp(BTCab, floor, false) ← LOKAL LYS
[ ] 2.7  Send til DM: elevatorEvents <- types.FromLocalToDM{
             Elevator:       elevator,
             CompletedOrder: completed,  // eller tom hvis ikke stoppet
             Obstructed:     obstruction,
         }

Eksempelkode:
```go
case floor := <-floorChan:
    elevator.CurrentFloor = floor
    elevator.ActiveStatus = true  // Bevis på liv
    hardware.SetFloorIndicator(floor)
    
    // Initialisering: første etasje
    if elevator.Behaviour == types.ElevatorMoving && 
       previousFloor == -1 {
        hardware.SetMotorDirection(types.Stop)
        elevator.MotorDirection = types.Stop
        elevator.Behaviour = types.ElevatorIdle
        previousFloor = floor
        elevatorEvents <- types.FromLocalToDM{Elevator: elevator}
        continue
    }
    previousFloor = floor
    
    var completed [config.NFloors][config.NButtons]bool
    
    if shouldStop(elevator) {
        hardware.SetMotorDirection(types.Stop)
        motorActiveChan <- false
        hardware.SetDoorOpenLamp(true)
        doorOpenChan <- true
        elevator.Behaviour = types.ElevatorDoorOpen
        elevator.MotorDirection = types.Stop
        
        completed = getCompletedOrders(elevator, floor)
        clearRequestsAtFloor(&elevator, floor)
        
        // Slå av CAB-lys lokalt
        if completed[floor][types.BTCab] {
            hardware.SetButtonLamp(types.BTCab, floor, false)
        }
    }
    
    elevatorEvents <- types.FromLocalToDM{
        Elevator:       elevator,
        CompletedOrder: completed,
        Obstructed:     obstruction,
    }
```

3. NEWORDER CASE - Mottatt ordre fra DecisionMaker
================================================================================
Trigger: DecisionMaker sender oppdatert request-matrise
Merk: DM har allerede satt hall-lys, LocalControl setter kun cab-lys

Steg-for-steg:
[ ] 3.1  Sammenlign gamle og nye cab-requests
[ ] 3.2  Sett cab-lys for NYE cab-ordrer: hardware.SetButtonLamp(BTCab, f, true)
[ ] 3.3  Lagre: elevator.Request = orders
[ ] 3.4  Hvis elevator.Behaviour == types.ElevatorIdle:
         [ ] 3.4.1 Sjekk om ordre i samme etasje → åpne dør
         [ ] 3.4.2 Ellers: beregn retning, start motor, start watchdog
[ ] 3.5  Send state til DM

Eksempelkode:
```go
case orders := <-newOrder:
    // Sett cab-lys for nye cab-ordrer (LocalControl ansvar)
    for f := 0; f < config.NFloors; f++ {
        if orders[f][types.BTCab] && !elevator.Request[f][types.BTCab] {
            hardware.SetButtonLamp(types.BTCab, f, true)
        }
    }
    
    elevator.Request = orders
    
    if elevator.Behaviour == types.ElevatorIdle {
        if hasRequestAtFloor(elevator, elevator.CurrentFloor) {
            hardware.SetDoorOpenLamp(true)
            doorOpenChan <- true
            elevator.Behaviour = types.ElevatorDoorOpen
        } else {
            dir := chooseDirection(elevator)
            if dir != types.Stop {
                hardware.SetMotorDirection(dir)
                motorActiveChan <- true
                elevator.MotorDirection = dir
                elevator.Behaviour = types.ElevatorMoving
            }
        }
    }
    
    elevatorEvents <- types.FromLocalToDM{
        Elevator:   elevator,
        Obstructed: obstruction,
    }
```

4. DOORCLOSEDCHAN CASE - Dør skal lukkes (timer utløpt)
================================================================================
Trigger: Dørtimer utløper (3 sekunder)
Merk: Hvis obstruction → restart timer, hold døren åpen

Steg-for-steg:
[ ] 4.1  Sjekk obstruction:
         [ ] Hvis obstruction == true:
             [ ] doorOpenChan <- true  (restart timer, hold åpen)
             [ ] Send state med Obstructed=true til DM
             [ ] continue
[ ] 4.2  Slå av door light: hardware.SetDoorOpenLamp(false) ← LOKAL LYS
[ ] 4.3  Velg retning: dir := chooseDirection(elevator)
[ ] 4.4  Hvis dir != types.Stop:
         [ ] Start motor, watchdog, sett Moving
[ ] 4.5  Ellers: sett Idle
[ ] 4.6  Send state til DM

Eksempelkode:
```go
case <-doorClosedChan:
    if obstruction {
        doorOpenChan <- true  // Hold døren åpen
        elevatorEvents <- types.FromLocalToDM{
            Elevator:   elevator,
            Obstructed: true,
        }
        continue
    }
    
    hardware.SetDoorOpenLamp(false)
    
    dir := chooseDirection(elevator)
    if dir != types.Stop {
        hardware.SetMotorDirection(dir)
        motorActiveChan <- true
        elevator.MotorDirection = dir
        elevator.Behaviour = types.ElevatorMoving
    } else {
        elevator.Behaviour = types.ElevatorIdle
    }
    
    elevatorEvents <- types.FromLocalToDM{
        Elevator:   elevator,
        Obstructed: obstruction,
    }
```

5. MOTORINACTIVECHAN CASE - Watchdog Timeout (HEIS IKKE ALIVE)
================================================================================
Trigger: Motor har kjørt >4 sekunder uten å nå etasje
Betydning: Heisen har STOPPET/STUCK - ikke lenger "alive"

Steg-for-steg:
[ ] 5.1  elevator.ActiveStatus = false  ← KRITISK: Heisen er ikke alive
[ ] 5.2  hardware.SetMotorDirection(types.Stop)  (sikkerhet)
[ ] 5.3  Logg feil
[ ] 5.4  Send til DM med ActiveStatus = false
         → DM må re-allokere hall-ordrer til andre heiser

Eksempelkode:
```go
case <-motorInactiveChan:
    elevator.ActiveStatus = false  // IKKE ALIVE
    hardware.SetMotorDirection(types.Stop)
    elevator.MotorDirection = types.Stop
    
    fmt.Println("ERROR: Motor watchdog timeout - elevator not alive")
    
    elevatorEvents <- types.FromLocalToDM{
        Elevator:   elevator,
        Obstructed: obstruction,
    }
    
    // Valgfritt: Prøv å restarte etter en stund
    // Eller vent på manuell reset
```

Eksempelkode:

    }
    // Hall-lys settes av DecisionMaker
    
    elevatorEvents <- types.FromLocalToDM{

8. HJELPEFUNKSJON: shouldStop(elevator) bool
================================================================================
Logikk: Skal heisen stoppe i denne etasjen?

```go
func shouldStop(e types.Elevator) bool {
    floor := e.CurrentFloor
    dir := e.MotorDirection
    
    // Alltid stopp for cab
    if e.Request[floor][types.BTCab] {
        return true
    }
    
    // Stopp for hall i riktig retning
    switch dir {
    case types.Up:
        if e.Request[floor][types.BTHallUp] {
            return true
        }
        // Stopp hvis ingen flere over
        if !requestsAbove(e) && e.Request[floor][types.BTHallDown] {
            return true
        }
    case types.Down:
        if e.Request[floor][types.BTHallDown] {
            return true
        }
        // Stopp hvis ingen flere under
        if !requestsBelow(e) && e.Request[floor][types.BTHallUp] {
            return true
        }
    case types.Stop:
        // Sjekk begge retninger
        if e.Request[floor][types.BTHallUp] || e.Request[floor][types.BTHallDown] {
            return true
        }
    }
    return false
}
```

9. HJELPEFUNKSJON: chooseDirection(elevator) MotorDirection
================================================================================
Logikk: Hvilken retning skal heisen kjøre?

```go
func chooseDirection(e types.Elevator) types.MotorDirection {
    switch e.MotorDirection {
    case types.Up:
        if requestsAbove(e) {
            return types.Up
        } else if requestsBelow(e) {
            return types.Down
        }
    case types.Down:
        if requestsBelow(e) {
            return types.Down
        } else if requestsAbove(e) {
            return types.Up
        }
    case types.Stop:
        if requestsAbove(e) {
            return types.Up
        } else if requestsBelow(e) {
            return types.Down
        }
    }
    return types.Stop
}
```

```go
func getCompletedOrders(e types.Elevator, floor int) [config.NFloors][config.NButtons]bool {
    var completed [config.NFloors][config.NButtons]bool
    
    // Cab alltid
    if e.Request[floor][types.BTCab] {
        completed[floor][types.BTCab] = true
    }
    
    // Hall basert på retning
    switch e.MotorDirection {
    case types.Up:
        if e.Request[floor][types.BTHallUp] {
            completed[floor][types.BTHallUp] = true
        }
        if !requestsAbove(e) && e.Request[floor][types.BTHallDown] {
            completed[floor][types.BTHallDown] = true
        }
    case types.Down:
        if e.Request[floor][types.BTHallDown] {
            completed[floor][types.BTHallDown] = true
        }
        if !requestsBelow(e) && e.Request[floor][types.BTHallUp] {
            completed[floor][types.BTHallUp] = true
        }
    case types.Stop:
        completed[floor][types.BTHallUp] = e.Request[floor][types.BTHallUp]
        completed[floor][types.BTHallDown] = e.Request[floor][types.BTHallDown]
    }
    return completed
}
```

```go
func clearRequestsAtFloor(e *types.Elevator, floor int) {
    // Clear cab (LocalControl styrer cab)
    e.Request[floor][types.BTCab] = false
    
    // Clear hall basert på retning
    switch e.MotorDirection {
    case types.Up:
        e.Request[floor][types.BTHallUp] = false
        if !requestsAbove(*e) {
            e.Request[floor][types.BTHallDown] = false
        }
    case types.Down:
        e.Request[floor][types.BTHallDown] = false
        if !requestsBelow(*e) {
            e.Request[floor][types.BTHallUp] = false
        }
    case types.Stop:
        e.Request[floor][types.BTHallUp] = false
        e.Request[floor][types.BTHallDown] = false
    }
    // MERK: Hall-lys settes IKKE av her - DM gjør det
}
```

12. HJELPEFUNKSJONER: requestsAbove/Below
================================================================================
```go
func requestsAbove(e types.Elevator) bool {
    for f := e.CurrentFloor + 1; f < config.NFloors; f++ {
        for b := 0; b < config.NButtons; b++ {
            if e.Request[f][b] {
                return true
            }
        }
    }
    return false
}

func requestsBelow(e types.Elevator) bool {
    for f := 0; f < e.CurrentFloor; f++ {
        for b := 0; b < config.NButtons; b++ {
            if e.Request[f][b] {
                return true
            }
        }
    }
    return false
}

func hasRequestAtFloor(e types.Elevator, floor int) bool {
    for b := 0; b < config.NButtons; b++ {
        if e.Request[floor][b] {
            return true
        }
    }
    return false
}
```
